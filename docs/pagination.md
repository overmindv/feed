# Страницы ленты

Первый запрос: `GET /v1/feed?limit=50&cursor=`. Если в ответе есть
`nextCursor`, передайте его как `cursor` в следующий запрос. Если поля нет,
дальше карточек нет. `limit` принимает значения от 1 до 100, по умолчанию 50.

Курсор задает границу по времени события с точностью до микросекунд и ID.
При совпадении обоих полей карточка материала идет первой. Новые карточки
выше этой границы увидит следующий запрос первой страницы. Опоздавшие
события ниже границы могут попасть на следующие страницы.

Курсор не фиксирует снимок БД. Скрытие карточки действует сразу, а новая
публикация материала может изменить его место в ленте. Курсор не проверяет
права вместо внутреннего токена.

Старый запрос с `offset` продолжает работать. Передача `cursor` вместе
с `offset` или неверный курсор дают `400 VALIDATION_ERROR`.
